# Your SkillTree starter kit

Built from your plan at skilltreeos.ai. 6 starter skills for Helping in coaching maybe, covering about 10 hours a week of your own time.

## What's in here

1. `skills/cold-email-drafting/SKILL.md` with its context file `sales/offer.md`
2. `skills/follow-up-drafting/SKILL.md` with its context file `deals/follow-up-cadence.md`
3. `skills/script-writing/SKILL.md` with its context file `marketing/voice.md`
4. `skills/meeting-follow-ups/SKILL.md` with its context file `ops/meeting-recap.md`
5. `skills/onboarding-journeys/SKILL.md` with its context file `customer/onboarding.md`
6. `skills/email-triage/SKILL.md` with its context file `admin/inbox-rules.md`

Plus `voice.md`, which every skill reads first.

## Install (Claude Code)

1. Copy the `skills` folder into your project's `.claude/` folder.
2. Copy the context files to the paths named above and fill in the blanks. Ten minutes, honestly.
3. Fill `voice.md` with three real messages you wrote. This one matters most.
4. Open Claude Code in the project and ask for the first skill by name.

## The order

Build them in the order listed. Each one is standalone; you do not need the first to run the second.
